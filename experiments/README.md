# Experiments directory: historical evidence and infrastructure fixtures

This directory predates the 2026-09-30 scope reset of `robotic_infra`.

Existing experiments are retained for:
- provenance and reproducibility;
- frozen negative/positive evidence;
- regression testing of data, timing and simulation contracts;
- reusable task fixtures when validating infrastructure.

They should **not** be interpreted as an active research roadmap for this repository.

New paper-specific hypotheses, architecture searches and submission-oriented experiment ladders should be created in a separate research repository. Only generic fixtures or compatibility updates that make the infrastructure more reliable should be added here by default.
