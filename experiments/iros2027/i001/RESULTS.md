# 2026-09-29：第一层证据存在，但强命题尚不成立

本轮支持：**在当前带噪声双指力代理中，近似相同的当前触觉可以对应不同的未来滑移；
过去的探测响应能提供额外预测信息。** 这仍是单一 disturbed-grasp 任务的受控机制证据。

本轮不支持：完整当前观测不足、interaction history 必不可少、ContactBelief 新架构有效。
高精度当前关节位置/速度已经能很好预测，不能忽略这个反例。

## 当前相近、未来不同

有探测的 96 个测试候选对中，57 对通过预设匹配门槛，覆盖 29/32 个独立 seed。
力逐通道差不超过 0.03 N，且关节位置/速度满足协议门槛；未来滑移标签相反。
将力门槛收紧到 0.01 N，仍有 25 对，覆盖 22 个 seed。

一个具体例子：seed 324、摩擦约 0.500 和 0.542，质量、夹爪指令、未来载荷完全相同。
当前六维力的最大差仅 0.001837 N（噪声标准差为 0.01 N），但一个在未来 50 ms 滑移，另一个不滑。
模型只使用过去及当前的带噪声观测，特权真值只用于标签、配对和评估。
近似相等并非严格相等；这不构成数学上的不可观测性证明。

## 未见 seed 上的预测

有探测条件，测试 96 episodes，31 个滑移阳性：

| 输入 | Brier ↓ | AUROC ↑ | 平衡准确率 ↑ |
| --- | ---: | ---: | ---: |
| 当前触觉 | 0.2137 | 0.5712 | 0.5407 |
| 250 ms 触觉历史 | 0.1386 | 0.8610 | 0.7310 |
| 历史时间置乱 | 0.1972 | 0.7092 | 0.5337 |
| 跨 seed 错配历史，保留当前帧 | 0.2282 | 0.4208 | 0.5000 |
| 最近 100 ms 触觉均值 | 0.2206 | 0.6223 | 0.5605 |
| 当前触觉 + 高精度 q/dq | **0.0517** | **0.9876** | **0.9293** |
| 250 ms 触觉 + q/dq 历史 | 0.0578 | 0.9851 | 0.9293 |

历史相对单帧的 Brier 改善为 0.0751，按测试 seed 聚类的 bootstrap 95% CI 为
[0.0451, 0.1038]。相对错配历史的改善为 0.0897 [0.0625, 0.1158]。
重复当前帧与单帧预测数值一致；随机训练标签的 AUROC 为 0.4888。

但加入 q/dq 后，历史改善为 **−0.0062 [−0.0209, 0.0083]**，没有显著增益。
这里 q/dq 是未加噪声的仿真精度；微小物理差异能被模型利用。不能为了支持假设删掉这个 baseline。

无探测时，历史也优于单帧，但最近 100 ms 简单平均与长历史相当，符合去噪这一替代解释。
有探测时 200 ms 上下文不覆盖早期探测响应，250 ms 才覆盖；这个时间窗口是协议人为安排的，
不能解释为一般接触任务存在普适的“250 ms 最佳记忆长度”。
时间置乱使当前模型变差，仅说明时间对齐对这个模型有用，不能证明任何无序统计量都无效。
置信区间以固定训练集和模型为条件，没有覆盖重新采样训练集的全部不确定性。

## 下一步研究应针对的缺口

1. 校准或系统扫描本体观测精度，检查当前 q/dq 优势来自可测物理信息还是仿真精度细节；
   传感分辨率扫描应标为新实验，不能事后修改本轮主判据。
2. 随机化探测时刻、方向和夹爪动作，保留相同未来输入，检验动作条件化是否有独立收益。
3. 在此之后验证学到的状态是否改善闭环控制，再加入第二种接触任务。

本轮没有 RGB 触觉、新神经架构、学习闭环控制、跨物体/跨任务泛化、公开 benchmark 或真机结果。
