# 2026-09-29：与讨论方向的对齐检查及原因诊断

结论：执行了受控抓持、近邻状态对、因果历史、相同未来输入和独立测试种子，
但把主要检验缩窄为“触觉历史优于单帧触觉”。尚未完整落实讨论中的
“完整当前观测有歧义，动作—触觉—本体历史恢复隐藏交互状态”。
本轮是有价值的初筛；不能把两项弱判据通过解释为 ContactBelief 第一层强机制证据完整建立。

## 实际发现

诊断读取原始 456 个 episode，不改变场景、原主协议和原主结果。
新增特征消融仍沿用原 train/validation/test 划分及同一核超参数网格；这是看过测试结果后的
事后诊断，不作为新的独立验证结论。源脚本、checkpoint 与数值保存于：
`runs/i001-aliasing/20260929-163530-567217-i001_aliasing/diagnosis-20260929-164512/`。

有探测条件，96 个测试 episode：

| 当前输入 | Brier | AUROC |
| --- | ---: | ---: |
| 六维力代理 | 0.2137 | 0.5712 |
| 仅两个指关节位置 | 0.0255 | 0.9960 |
| 仅机械臂关节位置 | 0.1797 | 0.7762 |
| 仅机械臂关节速度 | 0.1547 | 0.8337 |
| 全部当前 q/dq | 0.0519 | 0.9881 |

强预测信息主要能从当前指关节位置获得，不需要先假定历史模型训练失败。
采集使用 `qpos[:9]`、`qvel[:9]`，对应机器人七轴和两指；物体自由关节追加在其后。
特征函数只取 anchor 及以前的数据，未发现直接把未来标签、摩擦参数或物体状态拼入输入。

## 原因一：配对容差与模型观测精度不一致

`config.yaml` 允许两个指关节的位置差 <= 0.0001 m（100 μm）即算相近；
`collect.py` 却直接保存完整浮点 q/dq，不加测量噪声，也没有编码器量化。
`evaluate.py` 再按训练标准差缩放，微小的可重复位置差异仍能被模型利用。
有探测训练集的单指位置标准差约 9.09 μm，远小于配对容差。

已展示的 seed 324 例子，两条轨迹的单指位置差约 3.714 μm，
当前力最大差约 0.001837 N，未来标签相反。它们满足人为“接近”门槛，
但并不是模型不可区分的当前输入。

事后敏感性扫描：对 q/dq 按各自 SI 单位作舍入，步长从 1e-6 到 1e-4 时，
当前触觉 + q/dq 的 AUROC 从 0.9861 降至 0.5737。
这是混合通道的数值精度扫描，**不是实际编码器精度校准**，也不是据此选一个
能让历史赢的噪声强度。它只支持“结果对本体观测精度敏感”。
目前不能确定微小位移信息在真实系统中是否可测、是否稳定，或有多少来自接触求解设置；
仍需传感器和时间步/接触参数验证，不能直接称为仿真漏洞。

## 原因二：主要任务是隐藏摩擦辨识

同一方块、固定姿态和固定未来载荷下，主要变化是摩擦参数。
有/无探测两组测试标签分布均为：低摩擦区间 29/32 滑移，中间区间 2/32，高区间 0/32。
任务几乎沿摩擦区间分开，且当前指关节位置包含足够的预测信息。
这仍属于隐藏接触参数估计，但没有构造出“完整当前观测不足”的可靠任务。
这一结果不否定其他任务中的部分可观测性或 ContactBelief 研究方向。

## 原因三：没有检验动作条件化

逐 episode 核查，全部测试 episode 的 250 ms 历史内，机器人动作目标的时间变化为 0。
“探测”是向物体施加外力，机器人没有主动收紧/放松/移动。
虽然保存了 actions 数组，预测特征函数没有读取它。
所以本轮不能回答讨论中“相似触觉变化来自自身动作还是外界扰动”的问题，
也没有覆盖 tactile + action history / tactile + action + proprioception history 四组完整消融。

## 原因四：历史窗口与固定探测时间绑定

探测固定在预测时刻之前 250–240 ms，200 ms 历史看不到，250 ms 历史才能看到。
因此 250 ms 显著变好说明该窗口纳入了一次有信息的过去事件，
不能推出普适的 250 ms 有效时间尺度，也不能仅凭固定位置的历史响应宣布学到了 belief state。

## 合理保留与需要纠正的部分

保留：相同后续输入、因果切片、真值/输入隔离、未见 seed、全部原始数据与负面对照。
使用简单核模型做机制初筛是合理的；第一步不需要强行训练新神经架构。

纠正：把“完整当前观测 + 已知动作”的强基线列为下一轮主检验；
观测匹配必须服从与模型输入一致且有依据的传感器模型。
需要同时设计固定摩擦下不同动态接触状态，以及不同隐藏参数的条件，避免只有单一摩擦阈值。
改变机器人过去动作和外界扰动，检验动作历史是否带来独立增益，保持未来输入的控制。
随机化探测时刻，设置同传感器、同计算预算的当前/历史/动作条件化模型。
使用新的冻结测试种子，报告正、负结果；不能通过事后加噪声来保证目标方法取胜。
