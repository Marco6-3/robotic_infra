# I001 第一层：受控接触代理中的观测混叠

目标是检验有限分辨率下的当前观测歧义，以及历史是否提供额外预测信息。允许得到负结果。
不预设 ContactBelief、新架构、动作历史必要性或控制收益成立。

## 物理干预

沿用 FR3 已知位置刚体抓取，1 kHz MuJoCo。每个 seed 固定质量、夹爪宽度、探测载荷。
三个摩擦区间各采样一次，两侧手指与物体使用一致系数；摩擦不作为预测输入。
每个条件分别跑有探测和无探测。2.4 秒施加 10 ms 的 1.8–2.2 N 向下探测力；之后卸载。
2.65 秒为预测时刻。此后所有 episode 采用**相同的 1.5 N 外力（20 ms 上升）**，
同 seed 的所有摩擦/探测条件保持完全相同的关节和夹爪控制。预测接下来的 50 ms 内是否
存在连续 5 ms 的接触切向速度 > 0.01 m/s。只在预测时刻成功夹持、双指接触、
速度 < 0.003 m/s 的 episode 上评估，排除已经滑动/掉落的平凡例子，并报告全部排除数。

预测时刻位于 `mj_step` 之前。特征只能读取该时刻及以前的观测；未来步数完整，
不把无未来记录的样本标为阴性。单帧为双指六维力代理，附加对照可读取当前 q/dq。
噪声为独立每通道 0.01 N 高斯噪声；各摩擦/探测 episode 使用独立噪声流。
隐藏速度、物体位置、摩擦、外力、标签和 seed 均不进入特征。
输入是 MuJoCo force proxy，不是 DIGIT/RGB，也不是实物触觉。

## 预先固定的证据判据

1. 同一测试 seed、同一探测条件内，不同摩擦 episode 在 anchor 的**无噪声**六维力
   逐通道差 <= 0.03 N，且 q/dq 差满足配置阈值；当前都稳定，后续控制/外力完全一致，
   未来标签相反。报告全部合格对、总候选对及 .01/.02/.03/.05 N 敏感性。
   .03 N 是既定噪声标准差的三倍，是有限分辨率判据；高精度原始状态仍可能可分。
2. 测试集上历史预测优于单帧，使用按 seed 聚类的配对 bootstrap 95% 区间；
   主指标 Brier loss 的改善区间下界 > 0。上下文长度与超参数只在 validation 上选。
   同时报告 balanced accuracy、AUROC、AP、混淆矩阵，不使用逐帧随机切分。
3. 对比无探测历史、重复当前帧、历史时间置乱和跨 episode 历史错配（保留当前帧）。
   重复当前帧应与单帧数值一致；错配会破坏过去与未来的对应。

两项主判据都满足，只支持“本任务、该代理和物理分布下，存在近似当前观测歧义，
过去探测响应含额外预测信息”。近邻对是机制示例，独立统计单位为 seed，不能把大量帧
或所有配对当成独立实验。探测动作固定，不能据此声称 action conditioning 必要。
无探测条件若同样有效，需考虑历史去噪及静态微小摩擦痕迹，不能宣称只靠动态状态恢复。

## 数据划分与模型

开发使用 seed=10 的六个摩擦点，开发记录在 runs/i001-development，绝不进入主评估。
训练 100–131、验证 200–211、测试 300–331；每 seed 三摩擦 × 两探测，共 456 episodes。
这些是未见物理 seed 的同分布测试，**不是**未见物体或未见摩擦区间泛化。

固定 RBF kernel ridge predictor，用均方距离定义核；所有输入版本拥有相同数量的
训练系数、相同核宽/正则候选，不新增深度架构。按训练样本拟合尺度，在验证 Brier
上选超参数；将预测截断到 [0,1]。有/无探测分别拟合并报告，二者不混池。
按独立 seed 保存数据，生成过程可跳过已完整保存的 episode；分析可独立重跑。
原始逐时刻观测/特权标签、anchor 状态、后续输入哈希、配置/源文件/模型资产哈希、
模型 checkpoint、全预测、配对和聚类区间均保存到新建运行目录。
