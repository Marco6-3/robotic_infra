# I001 / I002 共用接触实验基础

这是独立的 **MuJoCo 刚体接触代理实验**，没有替换 I002 原有的 DIGIT 双指 RGB 路线。
它用于验证物理任务、独立高频记录、因果历史与多频率控制是否真正连通；不包含学习模型。

## 运行

交互预览：`pixi run contact-play`（窗口内空格暂停、R 重来、N 下一条件、Q 退出）。
预览与批量运行共用配置和控制循环，预览不保存数据。完整操作见 [实验工作流](../../../docs/experiment_workflow.md)。

从项目根目录执行：

```bash
pixi run contact-foundation
pixi run python -m pytest -q -o addopts='' tests/test_contact_foundation.py
```

默认配置为 `experiments/iros2027/contact/config.yaml`。也可以运行：

```bash
pixi run python -m experiments.iros2027.contact.run --config /绝对路径/config.yaml --output /绝对路径/输出目录
```

每次运行新建目录，保存配置、源文件快照、代码和网格哈希、MuJoCo 版本、Git 状态与逐 episode 日志。
失败或中断会标记 attempt 失败；当前入口不支持从半个物理 episode 恢复。

## 任务与控制

- 原 FR3 模型、位置执行器、1 ms 物理步长与操作台保持不变，在内存中生成独立场景。
- 使用已知物体位置的 IK 轨迹下降、夹持、抬升；不是视觉定位或学习抓取。
- 方块是具有自由关节的动态刚体，靠接触摩擦夹持，没有焊接、吸附或抓取约束。
- 每个 seed 随机质量 55–75 g、摩擦 0.65–0.85、扰动力峰值 5.5–6.5 N。
- 两侧接触几何都设置摩擦，避免 MuJoCo 默认混合规则覆盖物体摩擦。
- 时间：0–0.7 s 下降，0.7–1.4 s 夹持，1.4–2.1 s 抬升，2.4 s 建立相对位移参考。
- 2.5–2.6 s 向下外力线性增至峰值，维持至 2.8 s，4 s 结束。
- 5 Hz scripted semantic 意图在 2.4–3.0 s 将目标开口从 32 mm 改为 34 mm，随后恢复；
  用于检验慢消息能否真的影响动作，不称为语义模型。
- 200 Hz 接触代理、100 Hz fast policy、1 kHz 控制；快环在抬升结束后启用。
- 快环只读带噪声且经过延迟通道的力代理，以切向/法向比阈值作规则修正。
  最大额外闭合 16 mm，每次 2 mm；观测力超过 12 N 时逐步撤回修正。
  这是软反馈限制，不保证硬力上限；评估另行检查真实力峰值。
- semantic 超过 250 ms 时回退至 32 mm；触觉超过 200 ms 时保持上一次有界残差。
- 所有速率均为仿真时间调度；日志中的墙钟耗时不代表 ROS 或硬件实时保证。

默认运行六个条件，共享相同 seed 的物理参数：固定控制、无延迟快环、触觉延迟 100 ms、
semantic 延迟 300 ms。另外增加无扰动的固定控制与快环对照。300 ms semantic 条件刻意超过过期阈值，用于检查回退路径，不是优劣比较。

## 数据与真值隔离

每个 episode 保存：

| 文件 | 内容 |
| --- | --- |
| `scene.xml` | 带随机化物理参数的场景；网格引用本机绝对路径 |
| `tactile.jsonl` | 200 Hz，采样和可用时间，两指各三个带噪声力通道 |
| `control.jsonl` | 1 kHz，实际提交的目标、残差、关节位置与速度 |
| `decisions.jsonl` | 100 Hz，消耗的触觉/semantic 时间戳、消息年龄与残差 |
| `semantic.jsonl` | 5 Hz，慢意图与计划投递时间 |
| `labels.jsonl` | 1 kHz，仅评估用：真实接触力、相对速度、物体位置、扰动和标签 |
| `summary.json` | 物理参数、计数、夹持结果、力峰值与时序指标 |

接触代理只统计目标物体与左右手指的接触。每指通道是法向合力、指腹坐标系 x/z 有符号力，
单位 N；不是压力分布、光学触觉图像或校准过的真实传感器。独立高斯噪声标准差为 0.01 N。
物理真值不进入规则控制器或历史加载器；标签文件单独保存。

`EpisodeHistory(episode_path).context(decision_ns, history_ms)` 提供 I001 四组消融所需输入：
`tactile`、`action`、`proprioception`，以及采样/可用时间。0 ms 返回最新可用单帧；
其他窗口相对最新可用源时间回溯，动作和本体状态按每个触觉源时间因果对齐。
它永远不读取 `labels.jsonl`。训练时仍须按 episode/物体/物理 seed 划分，不能按相邻帧随机切分。

## 指标与边界

- 抬升：2.4 s 时物体高度 > 0.49 m，且两指法向接触力 > 0.15 N。
- 滑移 onset：参考时刻之后，相对接触切向速度连续 5 ms > 0.01 m/s。
- 掉落：相对参考位移 > 40 mm 或物体高度 < 0.46 m；首次触发后保留失败状态。
- 恢复确认：扰动结束后连续 100 ms 相对接触速度 < 0.003 m/s、双指保持接触且物体高度 > 0.49 m。
- 保持成功：成功抬升、从未掉落、最后 200 ms 全部满足稳定条件；超力另外报告。
- `first_post_hold_correction_ns` 是 2.4 s 后首次闭合修正，不直接当成滑移反应延迟；
  提前修正可能先于滑移，且部分成功轨迹根本不发生滑移。

最初突加外力时固定策略与快环都失败，因此开发阶段使用 100 ms 上升载荷构建可恢复情形。
规则和阈值在开发种子上调试过，默认三个种子不能作为独立论文评估；需另设未见物体、
扰动和物理参数的测试集，加入无扰动对照与匹配预算 baseline。

当前补齐的是接触任务、观测、记录和规则闭环。视觉触觉渲染、空间触觉场、学习模型、
双向 learned token、RoboTwin 和真机验证仍未完成。
